# 04 后端接口文档

- 基地址：`http://<host>:3003`（生产经 nginx 反代 `/api`）。
- 框架：Express 4；统一前缀 `/api`。
- 所有路由注册于 `backend/src/server.js`；模块实现见 `backend/src/routes/*.js`。

## 1. 通用约定

### 1.1 统一响应结构
```json
{ "success": true, "message": "说明", "data": { ... } }
```
失败时 `success=false`，`message` 为错误原因。

### 1.2 鉴权头约定
- 后台接口需请求头 `Authorization: Bearer <accessToken>`（`accessToken` 来自登录/刷新）。
- refresh token 走 **HttpOnly Cookie**（名 `refresh-token`，path `/api/auth`）。
- 权限分级：`admin`（最高）/ `editor`（admin+editor）/ 匿名（公开读、登录、表单提交）。中间件实现在 `middleware/auth.js`。

### 1.3 分页 / 列表参数
`page`（页码，默认 1）、`limit`（每页条数，默认 10）、`search`（标题/内容搜索）、`tagIds` / `includeNoTags`（页面按标签过滤）。

### 1.4 限流（`server.js`）
见 [02-智能限流分级](./02-技术架构与代码结构.md#智能限流分级serverjs)：匿名/普通 1000 次 / 分钟/IP，admin 10000 次 / 分钟/IP。

### 1.5 错误码说明
| 情况 | HTTP | message |
| --- | --- | --- |
| 参数校验失败 / 数据重复 | 400 | 数据验证失败 / 数据已存在（`ER_DUP_ENTRY`） |
| 未认证 / 令牌无效 | 401 | 令牌无效（`JsonWebTokenError`）/ 令牌已过期（`TokenExpiredError`） |
| 无权限 | 403 | 由 `requireRole` 返回 |
| 资源不存在路径 | 404 | 接口不存在（默认兜底） |
| 服务器异常 | 500 | 服务器内部错误 |

## 2. Auth 认证 `/api/auth`

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| POST | `/login` | 公开 | 账号密码登录；下发 accessToken + 写 refresh HttpOnly Cookie + 登录日志 |
| POST | `/refresh` | Cookie | 用 refresh token 换新 access token（并轮换刷新令牌） |

| GET | `/check` | admin/editor | 校验身份，返回当前用户 |
| GET | `/profile` | admin/editor | 获取当前用户资料 |
| PUT | `/profile` | admin/editor | 更新资料/邮箱/密码（改密码需 `currentPassword`） |

## 13. News 新闻 `/api/news`

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | `/` | editor/admin | 分页列表 + 搜索（含未发布，供后台「新闻中心」） |
| GET | `/latest` | 公开 | 最新 N 条（只读 `published=1`；`pinFirst=true` 时置顶优先，再按日期倒序） |
| GET | `/batch` | 公开 | 按 id 批量取多条（只读 `published=1`，供「自定义」模式） |
| GET | `/id/:id` | 公开 | 单条详情 |
| POST | `/` | editor/admin | 新建新闻（`validateCreateNews` Joi） |
| PUT | `/:id` | editor/admin | 更新新闻（`validateUpdateNews` + `validateId`） |
| DELETE | `/:id` | editor/admin | 删除新闻（`validateId`） |

> 约定：列表响应 `{success, data, meta:{current_page, per_page, total, total_pages, has_next, has_prev}}`；`date` 入参仅接受 `YYYY-MM-DD`（否则置 `null`），出参为该格式字符串（`DATE_FORMAT`，避免 mysql2 返回 Date 对象）；公开读（`/latest`、`/batch`）只返回 `published=1`；增删改均带 `logActivity`。
