# 04 后端接口文档

- 基地址：`http://<host>:3003`（生产经 nginx 反代 `/api`）。
- 框架：Express 4；统一前缀 `/api`。
- 所有路由注册于 `backend/src/server.js`；模块实现见 `backend/src/routes/*.js`。

## 1. 通用约定

### 1.1 统一响应结构
```json
{ "success": true, "message": "说明", "data": { ... } }
```
失败时 `success=false`，`message` 为错误原因。

### 1.2 鉴权头约定
- 后台接口需请求头 `Authorization: Bearer <accessToken>`（`accessToken` 来自登录/刷新）。
- refresh token 走 **HttpOnly Cookie**（名 `refresh-token`，path `/api/auth`）。
- 权限分级：`admin`（最高）/ `editor`（admin+editor）/ 匿名（公开读、登录、表单提交）。中间件实现在 `middleware/auth.js`。

### 1.3 分页 / 列表参数
`page`（页码，默认 1）、`limit`（每页条数，默认 10）、`search`（标题/内容搜索）、`tagIds` / `includeNoTags`（页面按标签过滤）。

### 1.4 限流（`server.js`）
见 [02-智能限流分级](./02-技术架构与代码结构.md#智能限流分级serverjs)：匿名/普通 1000 次 / 分钟/IP，admin 10000 次 / 分钟/IP。

### 1.5 错误码说明
| 情况 | HTTP | message |
| --- | --- | --- |
| 参数校验失败 / 数据重复 | 400 | 数据验证失败 / 数据已存在（`ER_DUP_ENTRY`） |
| 未认证 / 令牌无效 | 401 | 令牌无效（`JsonWebTokenError`）/ 令牌已过期（`TokenExpiredError`） |
| 无权限 | 403 | 由 `requireRole` 返回 |
| 资源不存在路径 | 404 | 接口不存在（默认兜底） |
| 服务器异常 | 500 | 服务器内部错误 |

### 1.5 多语言 `lang` 参数

- 内容表（页面/文档/新闻/导航）与站点设置接口均支持 `?lang=<code>`（缺省 `'zh'`）。语言代码来自 `languages` 表（中文为 `zh`，其余为其 URL `suffix`）。
- 列表/详情按 `lang` 过滤；创建/更新在请求体带 `lang`。`slug` 唯一按 `(lang, slug)` 维度。
- 站点设置 `GET /settings?lang=` 返回「本语言优先、缺失回退 zh」的合并结果（仅本地化键分语言，共享键如 ICP/主题/联系方式保持全局）。

## 2. Auth 认证 `/api/auth`

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| POST | `/login` | 公开 | 账号密码登录（本地降级通道）；下发 accessToken + 写 refresh HttpOnly Cookie + 登录日志 |
| POST | `/refresh` | Cookie | 用 refresh token 换新 access token（并轮换刷新令牌） |
| POST | `/logout` | Cookie | 吊销当前刷新令牌并清 Cookie |
| GET | `/check` | admin/editor | 校验身份，返回当前用户 |
| GET | `/profile` | admin/editor | 获取当前用户资料 |
| PUT | `/profile` | admin/editor | 更新资料/邮箱/密码（改密码需 `currentPassword`；`auth_provider='keycloak'` 的用户禁改邮箱/密码） |
| POST | `/sso-exchange` | 公开 | SSO 一次性 code（60s/单次）换取本地会话，响应与 `/login` 同构 |
| GET | `/keycloak/methods` | 公开 | 已启用且配置完整的登录方法列表（登录页据此渲染按钮） |
| GET | `/keycloak/start/:method` | 公开 | 发起 OIDC 授权码流程（state+nonce+PKCE S256），302 到对应 realm 的 Keycloak |
| GET | `/keycloak/:method/callback` | 公开 | 每个方法实例的独立回调地址：换 token、认领/建户并落角色、签发一次性 code，302 回 `/admin/sso?code=` |

**Keycloak SSO 说明**（OIDC 授权码，实现在 `routes/keycloak.js` + `utils/keycloakClient.js` + `utils/authMethods.js`）：

- **方法实例化（Wiki.js 风格）**：`local` 固定存在、不可停用/删除；Keycloak 方法为可动态新增的实例（随机 method_key），连接配置（`issuer`/`clientId`/`clientSecret`）在后台「登录管理」页填写，**存数据库** `auth_methods.config` 列（JSON），改完即时生效。
- **登录方法开关存数据库**（`auth_methods` 表）：`is_enabled`、`display_name`、`sort_order`、`auto_create`、`auto_create_role`。已启用且配置完整的方法才显示在登录页（公开端点 `GET /api/auth/keycloak/methods`）。
- **创建账号开关语义**：local 方法 `auto_create`=允许后台用户管理页新建/删除账号并分配角色（默认开）；keycloak 方法 `auto_create`=该实例用户首次 SSO 登录自动建户，角色取 `auto_create_role`（默认关，仅已登记账号可登录，不覆盖本地角色）。
- 账号认领规则：`keycloak_id` 命中直接登录 → 否则 **email 精确唯一命中**认领（保留本地密码与角色）→ `auto_create` 开启时建新用户（username 撞名自动加后缀，密码为不可用哈希）。
- 护栏：local 不可停用/删除；开启自动建户必须选择角色组；本地管理关闭时新建/删除接口返回 403。
- 本地账号密码登录保留作为 Keycloak 故障时的降级通道；Express 鉴权中间件与前端 401 refresh 机制不变。

## 19. Content 内容版本 `/api/content`

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | `/status` | 公开（弱网条件下发给该请求） | 返回各缓存数据源最近 `updated_at`，供前端浏览器缓存做「条件更新」比对 |

响应：
```json
{ "success": true, "data": { "navigation": "2026-...", "settings": "2026-...", "news": "2026-...", "languages": "2026-..." } }
```

- 支持 `?lang=<code>`（缺省 `zh`）。
- `navigation`/`news`/`languages` 取各表最近 `updated_at`（条件与对应公开读取一致，如仅已发布/活跃）；`settings` 取 `lang IN ('zh', ?)` 最近 `updated_at`（与设置合并口径一致）。
- 依赖各表已有 `updated_at`，不改表。前端把「写缓存时的版本」与最新版本比对，实现有缓存先展示、内容已变再重拉。完整方案见 [07](./07-浏览器缓存与弱网回退.md)。
