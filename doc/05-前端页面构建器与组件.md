# 05 前端页面构建器与组件

> 可视化建站核心，位于 `frontend/src/components/PageBuilder/` 与 `frontend/src/lib/`。

## 1. 架构分层

```
后台编辑        frontend/src/components/PageBuilder/
├── PageBuilder.tsx          # 构建器主体：画布 + 拖拽 DnD + 属性面板
├── ComponentLibrary.tsx     # 左侧组件库（按类目拖入画布）
├── ComponentEditor.tsx      # 属性编辑区（依据组件类型切换编辑器）
├── AiAssistModal.tsx        # AI 生成内容弹窗（调用 /api/ai/generate）
├── editors/
│   ├── registry.ts          # 组件类型 → 编辑器的映射注册表
│   ├── editorRenderers.tsx  # 各编辑器渲染分发
│   ├── customEditors.tsx    # 通用/自定义编辑器
│   ├── common/              # 公共子控件（TextFields、MediaPicker、IconColor、CyberEffects、WidthBackground）
│   └── <Xxx>Editor.tsx      # 每种组件一个专用编辑器
├── previews/                # 编辑态预览
├── hooks/useAssetPicker.ts  # 素材选择
└── dragTypes.ts             # DnD 类型常量

组件定义（注册/元数据）   frontend/src/lib/componentDefinitions/*.ts
                        （textComponents / imageComponents / cardComponents / cyberComponents / uncategorizedComponents）

数据落库               pages.template_data（JSON，含 components[]）

前台渲染               frontend/src/lib/pageContent/renderers/*.ts
                        ← pages/pages/[slug].tsx 拉取后按 type 分发渲染
```

## 2. 工作流程

1. **登入后台** → 页面 → 进入构建器 `PageBuilder.tsx`。
2. 从 `ComponentLibrary` 拖入组件（`react-dnd`），`ComponentEditor` 按组件类型渲染专用 `editors/<Type>Editor`。
3. 属性编辑结果汇总为组件的 `props`，存为 `pages.template_data.components[]`（每项形如 `{ id, type, props }`）。
4. 保存 → `PUT /api/pages/:id`。
5. 前台 `pages/[slug].tsx` 读取 `template_data`，按 `type` 在 `lib/pageContent` 找到对应渲染器，输出带主题 token 的 HTML/React。

## 3. 组件类型清单

来自 `lib/componentDefinitions/*.ts` 与 `editors/`。核心页面组件（type）：

`text-block` · `hero` · `banner-carousel` · `logo-wall` · `logo-scroll` · `image-block` · `image` · `image-text` · `image-text-horizontal` · `feature-grid` · `feature-grid-large` · `stats-section` · `pricing-cards` · `team-grid` · `timeline` · `testimonials` · `news-list` · `contact-form` · `call-to-action` · `faq-section` · `link-block` · `raw-html` · `rich-text` · `table` · `video-player` · `product-showcase-card` · `cyber-timeline` · `cyber-showcase` · `cyber-super-card`（+ 少量占位/工具类型）

（`array`/`email`/`textarea` 等为字段/内部类型，非页面组件。）

每个组件常含公共属性和专属属性：`widthOption`（full/constrained…）、`backgroundColorOption`、以及该组件独有字段（如 banner-carousel 的 `slides/autoPlay/interval`、pricing-cards 的 `plans/recommended`）。

## 4. 编辑器公共子控件（`editors/common/`）

| 控件 | 作用 |
| --- | --- |
| `TextFieldsEditor` | 标题/副标题/描述等文本框 |
| `MediaPickerField` | 选取素材/系统内置素材（`AssetPickerModal`） |
| `IconColorControls` | 图标颜色与着色模式（custom/default） |
| `CyberEffectsEditor` | 未来风特效（流动光/发光/描边） |
| `WidthBackgroundEditor` | 版心宽度与背景色选项 |

## 5. 主题 / 字体系统

- **主题定义** `frontend/src/styles/themes.ts`：内置 10 款主题——`serene-white`、`neo-futuristic`、`corporate-blue`、`classic-blue`、`elegant-dark`、`starry-night`、`emerald-forest`、`royal-amber`、`mystic-purple`、`minimal-pro`。
  - `applyTheme(theme)`、`getThemeById(id)`、`setCustomThemePalette(palette)` 应用于 `_app.tsx`。
- **语义化色板** `styles/themeComponents.ts`：`applyIsolatedThemeVariables(theme)` 注入 `--semantic-*` CSS 变量供各组件复用（浅/深主题层次自适应）。
- **字体** `styles/fontLoader.ts`：`applyFont(id, {name, url})` 动态加载 Google Font / 自定义字体；`_app.tsx` 依据 `settings.site_font{,_custom_name,_url}` 应用。
- **主题背景** `components/theme-backgrounds/` 与设置键 `theme_background`（pattern 等）联动。
- **overrides**：设置键 `theme_overrides`（accentSaturation / panelBrightness / borderRadiusScale / shadowDepth）提供参数化微调。
- **Motion** `styles/themeMotion.ts`：动画过渡参数。

> 主题最终来源：后台「主题定制」页 `pages/admin/theme-custom.tsx` 写回 `settings` 的 `site_theme` / `theme_overrides` / `custom_theme` 等；前台 `_app.tsx` 读取后全局应用。

## 6. 文档站（Docs）

- 前台路由 `pages/docs/[[...slug]].tsx`，走 `/api/docs/:slugPath(*)` 渲染。
- 后台 `pages/admin/docs/**` 管理树形文档（`docs` 表，type doc/folder，html/markdown 混排）。
- 组件：`components/docs/`（DocContent / DocsSidebar / DocTreePanel / DocForm / DocsLayout / DocsThemeToggle / DocParentSelector）。
- 富文本：CKEditor UMD（`frontend/public/ck-umd/`），用 `isomorphic-dompurify` 做 XSS 净化渲染。

## 7. 前台布局与全局

- `components/Layout.tsx` / `Header.tsx` / `Footer.tsx`：站点外壳，导航取 `/api/navigation`，页脚取 settings 的 `footer_layout`/`footer_social_links`。
- `contexts/SettingsContext.tsx`：全局站点设置 Provider，供主题/资料在各处消费。
- `hooks/useMetaInfo.ts`：按页动态刷新 SEO meta（title/description/OG）。
- `styles/globals.css` 及各组件私有 CSS（`text-block.css`、`link-block.css`、`table-block.css`、`cyber-*.css`、`docs-page.css`）在 `_app.tsx` 一并引入。
