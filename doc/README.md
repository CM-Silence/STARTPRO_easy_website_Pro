# STARTPRO easy-website 项目技术文档

> 面向开发 / 维护者的中文技术文档。本文档只描述代码与配置现状，不含业务操作手册。

## 项目一句话简介

前后端分离的企业官网建站系统：后台通过**可视化拖拽 PageBuilder** 编排页面组件、配置主题与站点资料、管理文档与通知；前台按 slug 渲染发布的页面。前端 Next.js 运行在 **3001** 端口，后端 Express API 运行在 **3003** 端口，数据库为 **MySQL**。

## 关键事实速记

- 库名 `pailink`；默认管理员账号 `admin`（详见 [03](./03-数据库设计.md#默认种子数据)）。
- 端口约定：前端 3001、后端 3003、后台管理信令端口 23080（nginx，仅用于暴露后台入口）。
- 后台路径 `/admin` 在前台 nginx 中被 `deny all` 屏蔽，后台通过独立端口 23080 访问。
- 静态资源路径：`/uploads`（用户上传）、`/system-default`（内置素材）、`/ck-umd`（CKEditor 前端静态资源）。

> ⚠️ 已知不一致：`init.sql` 自带种子数据（site_name「元兴信息官网」、备案号等）来自原始模板项目，而当前 `.env` 站点名为「深圳市电湃科技有限公司」，两者存在旧数据残留，详见 [02](./02-技术架构与代码结构.md#已知技术债与注意点)。
