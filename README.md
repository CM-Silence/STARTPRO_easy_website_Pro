# STARTPRO easy-website Pro

> 由 STARTPRO 开发的一体化企业官网 CMS。Pro版本在此之上新增了**UI优化**、**新闻持久化存储**、**多语言（i18n）**与**AI 多语言内容生成/同步**等功能。

一体化企业站/官网 CMS，提供可视化拖拽建站、赛博风模板、媒体管理、联系表单和通知中心。面向运营/市场/设计的朋友，后台只需直接拖组件、改文案、上传图片，即可发布官网；需要中英等多语言时，可接入AI，让AI一键把中文页面/设置/新闻翻译生成对应语言版本。

## 你能做什么

- **拖拽搭建页面**：选择模板块（Hero、Feature、Pricing、Timeline/Cyber-Timeline、Cyber Showcase、Contact 等），所见即所得。
- **主题和风格**：内置赛博风暗/亮主题，按钮、输入、卡片保持统一视觉。
- **导航与页面管理**：后台配置导航、页面、区块，保存即发布。
- **媒体库**：上传图片/文件到系统中，也可使用系统内置的默认素材。
- **联系表单与通知**：表单内建校验与防刷；配置SMTP后可收到邮件，后台通知中心支持测试、重发。

## 新增能力

### UI优化
- **导航栏悬停动画**：新增悬停动画，动画能够根据主题色动态变化。
- **切页动画**：新增切换路由动画，支持在系统设置页面中自定义滑块主标题/副标题（多语言适配也已接入）。
- **卡片悬停动画优化**：新增多种卡片悬停动画，用户可自由挑选并自定义动画持续时间。
- **更动感的页面**：每个组件现都支持**滚动浮现**以及**视差联动**功能，让你的网站更有活力。
- **亮暗色适配问题修复**：移除了原系统中自带的亮暗色适配，现在各组件的颜色只根据主题色来改变。
- **轮播图亮暗色适配**：因不同图片的背景有亮有暗，因此现在每一个轮播图都能单独设置文字颜色以及按钮亮暗色，适配更多场景。
- **其他优化**：修复了一些原版组件存在的BUG

### 新闻持久化存储
- **新增新闻库**：考虑到新闻是一个需要长期维护、新增、修改的内容，Pro版将新闻数据放在了数据库中实现持久存储，管理员可在后台管理页面中访问。
- **新闻列表重做**：新闻列表组件现直接对齐新闻持久存储的修改，能够展示最近的N条新闻，还支持置顶（无论时间始终优先展示）、自定义展示（指定展示的新闻）功能。
- **多语言适配**：在其他语言环境下，新闻列表能够自动映射到对应语言的新闻列表。

### 多语言（i18n）
- **语言管理**：后台「语言管理」可新增语言（显示名 + URL 后缀 + 启用开关），内置中文为默认（不可删改）。
- **数据库适配**：与语言相关的表，如页面、导航等，都已接入多语言，可在后台页面统一管理。
- **完全动态路由**：系统在请求期识别语言前缀，管理员只需在后台新增语言即可立即使用、无需重启/重构建。

### AI 多语言内容
- **AI一键生成/同步**：以中文内容为基底，后台可以使用「AI 同步」将中文页面/文档/新闻/导航同步到目标语言；AI同步功能生成的是独立页面，可在后台进行二次修改。
- **AI词条**：在「AI接入」页维护术语映射，翻译时强制保持术语一致（如“知识库 → Wiki”），多语言文案风格符合目标语言网页写作习惯。

## 快速上手（本地体验）

### 基础环境：Node.js ≥ 18、MySQL 8.0、nginx（可选）

```bash
# 安装依赖（进入项目根目录）
cd frontend && npm install
cd ../backend && npm install
```

### 数据库初始化/更新

`init.sql` ：已做安全性修改以及增量更新，**旧配置服务器运行一次即可对齐Pro版功能**，保证不覆盖、不删除原有数据。

```bash
# 建库建账号（示例库名 example，按需更换）
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS example DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; CREATE USER IF NOT EXISTS 'example'@'localhost' IDENTIFIED BY 'PASSWORD'; GRANT ALL ON example.* TO 'example'@'localhost'; FLUSH PRIVILEGES;"

# 配置数据库连接 / JWT 等
cp .env.example .env && vim .env

# 导入表结构
mysql -upailink -p pailink < ./init.sql
```

> 无 seed：首次需自行在后台创建管理员账号与站点资料/页面。创建首页时其 URL（slug）必须为 `pages/home`，否则无法作为首页打开。

### 启动服务

```bash
# 后端 API：http://localhost:3003
cd backend && npm start

# 前端：http://localhost:3001
cd frontend && npm run build && npm start
```

生产可用 pm2 守护两个进程（3001 前端 / 3003 后端）。

### 登录后台
打开 `http://localhost:3001/admin/login` ，默认账户如下：

账号：admin

密码：admin123

### 访问普通页面

打开 `http://localhost:3001` ，直接访问自己创建的页面（首页）。

注意，创建首页的URL必须是/pages/home，否则无法正常打开。

### 多语言与 AI 使用路径

1. 登录后台：`http://localhost:3001/admin/login`。
2. 「语言管理」添加语言（如英文 `en`），前台导航栏中会自动出现语言切换器。
3. 在「AI 接入」配置 AI 提供商（`api_key`/`model`），并按需维护「AI 词条」。
4. 在后台的页面/新闻/导航列表/系统设置页面，选中相应的行即可通过「AI 同步」功能，将中文内容同步到目标语言上。

## 创建与发布页面

1. 后台点击「新建页面」或编辑现有页面，在 Page Builder 中拖入组件，左侧改文字/图片/按钮链接，右侧实时预览。
2. 需要时间轴/赛博展示等特殊模块，直接选对应模板即可。
3. 切换主题/色彩检查视觉，保存后发布，前台立即生效。

## 联系表单与通知

- 表单：组件已接入 `/api/contact`，含校验、防刷（honeypot + rate-limit）。
- 邮件通知：后台「通知设置」填写 SMTP，可用「发送测试」验证；消息中心查看提交、标记已读、重发。

## 部署要点

- 前端：`cd frontend && npm run build && npm start`（3001）。
- 后端：`cd backend && npm start`（3003）。
- 反向代理：参考仓库根 `tech-website.conf` / `tech-website-BTpanel.conf`，区分前台 443/80 与后台 23080；`/admin` 在前台 nginx 中 `deny all`，后台经独立端口访问。
- 安全：用环境变量提供 DB/JWT/SMTP，首发后修改管理员密码，开启 HTTPS、防火墙与上传大小限制。
